# Cloud-only operating mode (no Cloudflare)
GitHub Actions runs the self-hosted gateway handler inside a temporary GitHub-hosted runner. There is no always-on HTTP endpoint. The workflow must be manually dispatched from the Actions tab, and only after explicit approval to send the prompt to both providers.
Prerequisites: secrets GROQ_API_KEY, OPENROUTER_API_KEY; variables AI_PROVIDER_FREE_TIERS_VERIFIED=true and ACTIONS_ZERO_COST_VERIFIED=true only after verifying no billable account exposure. GitHub Actions free allowances are finite, particularly for private repositories; no code can guarantee $0 charges if billing is enabled.
This workflow does not merge code, place trades, publish content, or automatically modify repositories. Its outputs appear in the job summary. It does not automatically route regular ChatGPT messages or create a public HTTPS service. Never send sensitive information.
